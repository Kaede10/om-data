# NPU资源用量查询脚本计算逻辑文档

## 1. 功能概述
根据用户选择的**维度**和**过滤值**，动态查询Prometheus中的NPU使用数据，返回用于图表展示的时间序列。

## 2. 参数说明
| 参数 | 类型 | 说明 |
|------|------|------|
| `start`/`end` | long | 时间范围（支持毫秒/秒） |
| `step` | int | 数据点间隔（秒），默认15秒 |
| `dimension` | string | 分组维度，默认`project` |
| `value` | string | 过滤值，支持逗号分隔多选，"All"表示全部 |

## 3. 核心计算流程

### 3.1 时间参数处理
- **时间戳归一化**：大于`100000000000L`（毫秒）的值自动除以1000转为秒
- **最大跨度限制**：若`(end - start) > 2678400`（31天），强制`start = end - 2678400`
- **自适应步长**：`step < 15`时设为15秒；若跨度>7天且`step < 3600`，强制设为3600秒

### 3.2 安全过滤器（固定）
所有查询**强制包含**以下排除条件（不可绕过）：
```
project!="unknown",
project!~".*(test|测试|昇思|coder|argo).*"
```
**目的**：自动过滤测试/临时项目，确保核心数据准确性。

### 3.3 动态过滤条件
当`value`有效（非空且非"All"）时，追加标签匹配：
```
维度=~"转义后的值（逗号→|）"
```
- 使用`prometheus.escapeRegex`防止正则注入
- 逗号分隔实现多值OR匹配（如`value=A,B`生成`A|B`）

### 3.4 PromQL查询生成
| 场景 | 查询语句 | 输出序列 |
|------|----------|----------|
| `value`为"All"或空 | `sum(custom_npu_total_used_count{固定过滤器})` | 1条："总利用" |
| `value`有具体值 | `sum by(维度)(custom_npu_total_used_count{固定过滤器, 维度=~"值"})` | N条：每个维度值一条 |

### 3.5 结果格式化
对查询返回的每个时间序列：
- **命名**：分组时使用维度值，否则用"总利用"
- **数据提取**：提取`[时间戳, 数值]`对构成`points`数组
- **输出**：`{"series": [{"name": "xxx", "points": [[t1,v1],...]}]}`

## 4. 关键特性
✅ **维度灵活**：可动态切换`project`、`cluster`等任意标签  
✅ **安全防护**：正则转义 + 固定黑名单双重防护  
✅ **性能优化**：自动限制跨度与步长，防止查询超时  
✅ **多值支持**：用逗号实现同一维度的多值OR筛选  

## 5. 使用示例
| 目标 | `dimension` | `value` | 结果 |
|------|-------------|---------|------|
| 查看总用量 | （默认） | `"All"` | 1条汇总线 |
| 按项目拆分 | `"project"` | `"pytorch,vision"` | 2条线（pytorch/vision） |
| 按集群拆分 | `"cluster"` | `"prod"` | 1条线（prod集群） |
