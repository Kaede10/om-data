## 二、新增指标定义

### 2.1 task_card_occupied_seconds_total（占用卡时）

> **Counter** | 任务从Pod启动到结束，占用的NPU卡总数 × 总运行时长。任务退出时上报累计值。

```json
{
  "version": "1.0",
  "name": "task_card_occupied_seconds_total",
  "desc": "任务累计占用NPU卡总秒数（占用卡数 × 总运行时长）",
  "timestamp": 1786351551389000,
  "data_list": [
    {
      "value": 21600.0,
      "label": {
        "task_id": "workflow-13069-20260908",
        "cluster": "ascend-hk-001-cluster",
        "account": "ascend_infra",
        "env": "cloud",
        "community": "mindstudio",
        "node": "os-node-created-2dq9v",
        "pod_name": "linux-aarch64-a2b3-1-m8kx4-runner-jhxkx-workflow",
        "pr": "vllm-project/vllm-ascend/.github/workflows/_selected_tests_upstream.yaml@refs/pull/13069/merge",
        "project": "参与开源统一资源池-香港-A2(910B3)",
        "npu_type": "910B",
        "region": "香港"
      }
    }
  ]
}
```

### 2.2 task_card_used_seconds_total（使用卡时）

> **Counter** | 任务实际使用NPU卡的总时长，仅包含有效计算时间。在计算段埋点累加，任务退出时上报累计值。

```json
{
  "version": "1.0",
  "name": "task_card_used_seconds_total",
  "desc": "任务累计实际使用NPU卡总秒数（实际使用卡数 × 实际计算时长）",
  "timestamp": 1786351551389000,
  "data_list": [
    {
      "value": 14400.0,
      "label": {
        "task_id": "workflow-13069-20260908",
        "cluster": "ascend-hk-001-cluster",
        "account": "ascend_infra",
        "env": "cloud",
        "community": "mindstudio",
        "node": "os-node-created-2dq9v",
        "pod_name": "linux-aarch64-a2b3-1-m8kx4-runner-jhxkx-workflow",
        "pr": "vllm-project/vllm-ascend/.github/workflows/_selected_tests_upstream.yaml@refs/pull/13069/merge",

  ]
}
```

## 四、标签说明

| 标签 | 说明 | 来源 |
|------|------|------|
| `task_id` | 任务唯一标识，如 `workflow-13069-20260908` | Pod 标签 `task-id`，通过 Prometheus relabel 提取 |
| `cluster` | 集群名称 | Pod 标签 / npu-exporter 配置 |
| `account` | 账户标识 | Pod 标签 / npu-exporter 配置 |
| `env` | 环境标识（如 `cloud`） | Pod 标签 / npu-exporter 配置 |
| `community` | 社区标识 | Pod 标签 / npu-exporter 配置 |
| `node` | K8s 节点名称 | Kubernetes downward API / npu-exporter |
| `pod_name` | Pod 名称 | Kubernetes downward API / npu-exporter |
| `npu_type` | NPU 型号（如 `910B`） | npu-exporter 采集 |
| `project` | 项目名称 | Pod 标签 |
| `region` | 地域（如 `香港`） | Pod 标签 / npu-exporter 配置 |
| `pr` | 关联的 PR 信息 | Pod 标签 |


## 五、指标新增与标签注入说明

### 5.1 需要新增的指标

| 指标 | 类型 | 上报方式 |
|------|------|---------|
| `task_card_occupied_seconds_total` | Counter | 任务代码通过 Prometheus Client 库暴露，或通过 Pushgateway 推送 |
| `task_card_used_seconds_total` | Counter | 任务代码通过 Prometheus Client 库暴露，或通过 Pushgateway 推送 |

### 5.2 需要增加标签的已有指标

| 指标 | 标签注入方式 |
|------|-------------|
| `custom_npu_total_occupied_count` | Prometheus relabel 从 Pod 标签 `task-id` 提取 |
| `custom_npu_total_used_count` | Prometheus relabel 从 Pod 标签 `task-id` 提取 |
| `npu_chip_info_utilization` | Prometheus relabel 从 Pod 标签 `task-id` 提取 |
| `npu_chip_info_hbm_utilization` | Prometheus relabel 从 Pod 标签 `task-id` 提取 |

### 5.3 Prometheus relabel 配置示例

```yaml
scrape_configs:
  - job_name: 'npu-exporter'
    kubernetes_sd_configs:
      - role: pod
    relabel_configs:
      - source_labels: [__meta_kubernetes_pod_label_task_id]
        target_label: task_id
        action: replace
```
