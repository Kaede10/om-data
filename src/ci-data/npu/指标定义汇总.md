## 二、新增指标定义

### 2.1 task_card_occupied_seconds_total（占用卡时）

> **Counter** | 任务从Pod启动到结束，占用的NPU卡总数 × 总运行时长。任务退出时上报累计值。

```json
{
  "version": "1.0",
  "name": "task_card_occupied_seconds_total",
  "desc": "任务累计占用NPU卡总秒数（占用卡数 × 总运行时长）",
  "timestamp": 1786351551389000,
  "data_list": [
    {
      "value": 21600.0,
      "label": {
        "pod_name": "linux-aarch64-a2b3-1-m8kx4-runner-jhxkx-workflow",
        "cluster": "ascend-hk-001-cluster",
        "account": "ascend_infra",
        "env": "cloud",
        "community": "mindstudio",
        "node": "os-node-created-2dq9v",
        "pr": "vllm-project/vllm-ascend/.github/workflows/_selected_tests_upstream.yaml@refs/pull/13069/merge",
        "project": "参与开源统一资源池-香港-A2(910B3)",
        "npu_type": "910B",
        "region": "香港"
      }
    }
  ]
}
```

### 2.2 task_card_used_seconds_total（使用卡时）

> **Counter** | 任务实际使用NPU卡的总时长，仅包含有效计算时间。在计算段埋点累加，任务退出时上报累计值。

```json
{
  "version": "1.0",
  "name": "task_card_used_seconds_total",
  "desc": "任务累计实际使用NPU卡总秒数（实际使用卡数 × 实际计算时长）",
  "timestamp": 1786351551389000,
  "data_list": [
    {
      "value": 14400.0,
      "label": {
        "pod_name": "linux-aarch64-a2b3-1-m8kx4-runner-jhxkx-workflow",
        "cluster": "ascend-hk-001-cluster",
        "account": "ascend_infra",
        "env": "cloud",
        "community": "mindstudio",
        "node": "os-node-created-2dq9v",
        "pr": "vllm-project/vllm-ascend/.github/workflows/_selected_tests_upstream.yaml@refs/pull/13069/merge",
        "project": "参与开源统一资源池-香港-A2(910B3)",
        "npu_type": "910B",
        "region": "香港"
      }
    }
  ]
}
```


## 三、已有指标（通过 pod_name 关联任务）

以下指标均已存在，**无需新增指标**，也**无需额外加标签**。`pod_name` 天然是 K8s Pod 的唯一标识，可直接作为任务标签使用。

### 3.1 custom_npu_total_occupied_count（占用卡数趋势）

## 四、标签说明

| 标签 | 说明 | 来源 |
|------|------|------|
| `pod_name` | **任务唯一标识**（Pod名称），如 `linux-aarch64-a2b3-1-m8kx4-runner-jhxkx-workflow` | Kubernetes downward API / npu-exporter |
| `cluster` | 集群名称 | Pod 标签 / npu-exporter 配置 |
| `account` | 账户标识 | Pod 标签 / npu-exporter 配置 |
| `env` | 环境标识（如 `cloud`） | Pod 标签 / npu-exporter 配置 |
| `community` | 社区标识 | Pod 标签 / npu-exporter 配置 |
| `node` | K8s 节点名称 | Kubernetes downward API / npu-exporter |
| `npu_type` | NPU 型号（如 `910B`） | npu-exporter 采集 |
| `project` | 项目名称 | Pod 标签 |
| `region` | 地域（如 `香港`） | Pod 标签 / npu-exporter 配置 |
| `pr` | 关联的 PR 信息 | Pod 标签 |


## 五、指标新增与使用说明

### 5.1 需要新增的指标

| 指标 | 类型 | 上报方式 | 关联维度 |
|------|------|---------|---------|
| `task_card_occupied_seconds_total` | Counter | 任务代码通过 Prometheus Client 库暴露，或通过 Pushgateway 推送 | 按 `pod_name` 关联任务 |
| `task_card_used_seconds_total` | Counter | 任务代码通过 Prometheus Client 库暴露，或通过 Pushgateway 推送 | 按 `pod_name` 关联任务 |

### 5.2 已有指标（直接使用，无需额外操作）

| 指标 | 关联方式 |
|------|---------|
| `custom_npu_total_occupied_count` | 已有 `pod_name` 标签，直接按 `pod_name` 过滤 |
| `custom_npu_total_used_count` | 已有 `pod_name` 标签，直接按 `pod_name` 过滤 |
| `npu_chip_info_utilization` | 已有 `pod_name` 标签，直接按 `pod_name` 过滤 |
| `npu_chip_info_hbm_utilization` | 已有 `pod_name` 标签，直接按 `pod_name` 过滤 |

### 5.3 任务看板表格查询示例

| 列名 | PromQL 查询 |
|------|------------|
| 任务（Pod名称） | `label_values(pod_name)` |
| 占用卡时 | `task_card_occupied_seconds_total{cluster="$cluster"} / 3600` |
| 使用卡时 | `task_card_used_seconds_total{cluster="$cluster"} / 3600` |
| 平均AI Core利用率 | `avg by (pod_name) (npu_chip_info_utilization{cluster="$cluster"})` |
| 平均HBM带宽利用率 | `avg by (pod_name) (npu_chip_info_hbm_utilization{cluster="$cluster"})` |

### 5.4 单个任务趋势图查询示例

当用户点击某个任务时（`pod_name="linux-aarch64-a2b3-1-m8kx4-runner-jhxkx-workflow"`）：

| 占用卡数 | `custom_npu_total_occupied_count{pod_name="linux-aarch64-a2b3-1-m8kx4-runner-jhxkx-workflow"}` |
| 使用卡数 | `custom_npu_total_used_count{pod_name="linux-aarch64-a2b3-1-m8kx4-runner-jhxkx-workflow"}` |
| AI Core利用率 | `npu_chip_info_utilization{pod_name="linux-aarch64-a2b3-1-m8kx4-runner-jhxkx-workflow"}` |
| HBM带宽利用率 | `npu_chip_info_hbm_utilization{pod_name="linux-aarch64-a2b3-1-m8kx4-runner-jhxkx-workflow"}` |
